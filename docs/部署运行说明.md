# 店小约 部署运行说明

> 文档版本：1.0
> 更新时间：2026-09-15
> 面向读者：要把本项目在自己电脑上跑起来的任何人。不需要会写代码，但需要会装软件、改配置文件。
> 业务背景见《项目介绍.md》，架构设计见《代码技术架构.md》。

## 1. 一图看懂部署全景

```text
                你的电脑（或服务器）
 ┌──────────────────────────────────────────────────┐
 │                                                  │
 │  浏览器 http://localhost:5173                    │
 │    │  React 前端（Vite 开发服务，端口 5173）      │
 │    │  所有 /api 请求转发给后端                    │
 │    v                                             │
 │  Spring Boot 后端（Java 17，端口 8080）           │
 │    │            │            │                   │
 │    │            │            +---> DeepSeek API   │
 │    │            │                 （外网，可不用） │
 │    │            +---> Redis（端口 6379，可不用）   │
 │    +----------------> MySQL（端口 3306，必须）    │
 │                        库名 shop_booking          │
 └──────────────────────────────────────────────────┘
```

三个依赖的"必须/可选"：

```text
MySQL 8.0    必须   唯一业务数据源，订单全在这，丢不得
Redis 7      可选   只存可重建状态（短期记忆/幂等键/限流），
                    没装系统自动降级，清空它不丢任何订单
DeepSeek     可选   不填 Key 可正常启动，对话降级为
                    FAQ 关键词匹配 + 自动转人工
```

## 2. 环境要求

```text
软件          版本下限      用途                检查命令
─────────────────────────────────────────────────────────
JDK           17           跑后端              java -version
Maven         3.8          构建后端            mvn -v
Node.js       18           跑前端开发服务       node -v
MySQL         8.0          业务数据库          （服务里看）
Redis         7（可选）     缓存               （服务里看）
操作系统       Windows 10+  本文档以 Windows 为例
```

安装提示：

- JDK 装好后 `java -version` 要显示 17 或更高；显示 1.8 说明装的还是 JDK 8，需要换。
- Maven 和 Node 装好后要重开一个终端窗口，PATH 才会生效。
- MySQL 用 zip 免装版或安装器都行，记住 root 密码，后面要填。
- Redis：Windows 官方不直接发布。推荐用项目自带方案——启动脚本检测到未装时会询问是否一键安装便携版（约 12MB，装在项目 runtime\ 内，仅本项目可用），或手动运行 `scripts\setup-redis.ps1 -Start`；也可以用 Memurai、WSL 里的 redis-server，或直接跳过（系统会自动降级运行，订单不丢）。

## 3. 首次部署：五步走

```text
 ①导入数据库     ②复制配置文件    ③填三个配置     ④一键启动      ⑤注册开店
 ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
 │执行建库  │ -> │.env.example│ -> │DB_PASSWORD│ -> │启动脚本  │ -> │注册owner │
 │SQL脚本   │    │复制为.env │    │JWT_SECRET │    │自动开浏览器│    │走开店向导 │
 └─────────┘    └─────────┘    │API_KEY(可空)│    └─────────┘    └─────────┘
                                └─────────┘
     一次性          一次性          一次性         每次运行         一次性
```

### 第 ① 步：导入数据库（一次性）

在项目根目录打开 PowerShell：

```powershell
mysql -u root -p < database\sql\01_schema.sql
```

输入 MySQL 密码后，脚本会自动建库 `shop_booking` 和 10 张空表。
脚本只建结构、不含任何示例数据，跑多少遍都不会把已有数据弄坏（幂等设计）。

没有 mysql 命令？用图形工具也一样：Navicat / DBeaver / MySQL Workbench
连接本机 MySQL，打开 `database\sql\01_schema.sql` 整个执行一遍即可。

验证：连上 MySQL 执行 `USE shop_booking; SHOW TABLES;`，能看到 10 张表（users、shops、service_items、time_slots、bookings……）就对了。

### 第 ② 步：复制配置文件（一次性）

```powershell
copy backend-java\.env.example backend-java\.env
```

`.env` 是你的私密配置（已被 Git 忽略，不会被提交），`.env.example` 只是模板。

### 第 ③ 步：填写配置（一次性）

用记事本或任意编辑器打开 `backend-java\.env`，只需关心这几行：

```ini
DB_PASSWORD=你的MySQL密码        # ← 必填，改成第①步输入的那个密码

JWT_SECRET=please-change-this-to-a-random-secret-at-least-32-bytes!
                                # ← 必填，随便敲一段至少 32 个字符的乱码，
                                #    例如键盘乱按一串：k9!vTq2#mXz8...（别用示例值）

DEEPSEEK_API_KEY=               # ← 建议留空：启动后由老板在网页「店铺设置 →
                                #    AI 客服设置」中填写（AES 加密存库，改后即生效）；
                                #    Key 在 platform.deepseek.com 充值获取
```

其他行（DB_URL、REDIS_HOST、PORT……）保持默认即可，除非你的 MySQL/Redis
不在本机或改过端口。

### 第 ④ 步：一键启动（每次运行）

双击项目根目录「启动-店小约.bat」，或：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\toggle.ps1
```

脚本自动完成：

```text
检查 java/node/MySQL -> 校验 .env（首次运行向导自动生成）-> 前端无依赖则安装
-> 启动后端 8080（使用仓库自带 jar，日志 logs\backend.log）
-> 启动前端 5173（日志 logs\frontend.log）
-> 轮询就绪检查 -> 自动打开浏览器 -> 桌面生成「店小约」切换式快捷方式
```

首次成功启动后，桌面会出现一个快捷方式，之后日常启停只需双击它：

```text
店小约   一键切换：未运行 -> 启动（检查环境 -> 启动前后端 -> 打开浏览器）
                 已运行 -> 停止（释放 8080/5173，结束后端/前端及其子进程）
```

看到这个框就是成功：

```text
=====================================================
 店小约已启动！
 顾客对话入口   http://localhost:5173
 老板/店员登录   http://localhost:5173/login
 首次使用：注册 owner 账号 -> 完成开店向导 -> 生成档期
 停止服务：双击桌面「店小约」（再点一次即停止）
 或：本窗口按 Ctrl+C / 直接关闭窗口
=====================================================
```

停止服务（三选一）：再双击一次桌面**「店小约」**（检测到运行中会自动停止）；或在启动窗口按 **Ctrl+C**；
或直接关掉启动窗口（下次启动前若提示端口占用，双击一次「店小约」即可清理）。

### 第 ⑤ 步：注册账号并开店（一次性）

```text
浏览器打开 http://localhost:5173/login
   |
   ├─ 注册页选角色 owner（老板）-> 登录后顶部会提示走"开店向导"
   │      向导 4 步：店铺信息 -> 营业时间 -> 服务项目（可用行业模板）-> 确认生成
   │      完成后 30 天档期自动生成，AI 客服即刻上岗
   │
   ├─ 想加店员：再注册一个角色 staff 的账号，给员工用
   │
   └─ 想体验顾客视角：直接开新标签页访问 http://localhost:5173
          游客无需注册即可和 AI 对话、下单（按浏览器会话识别；注册/登录后数据归入账号，跨设备可见）
```

## 4. 手动启动（不想用脚本时）

后端（项目根目录下执行）：

```powershell
# 读取 .env 里的变量到当前会话，再启动（Spring Boot 本身不读 .env 文件）
Get-Content backend-java\.env | Where-Object {$_ -match '^[^#].+='} | ForEach-Object {
    $i = $_.IndexOf('='); Set-Item -Path ("Env:" + $_.Substring(0,$i).Trim()) -Value $_.Substring($i+1).Trim()
}
cd backend-java
mvn spring-boot:run            # 开发模式；或先 mvn package -DskipTests 再 java -jar target\shop-booking-backend.jar
```

前端（另开一个终端）：

```powershell
cd frontend
npm install                    # 首次
npm run dev                    # 启动在 5173，/api 自动代理到 8080
```

前端生产构建（部署到静态服务器时用）：

```powershell
cd frontend
npm run build                  # 产物在 frontend\dist\，任意静态服务器可托管
```

注意：生产部署时前端不再走 Vite 代理，需要把 `/api` 反向代理到后端
（Nginx 配一个 `location /api { proxy_pass http://127.0.0.1:8080; }` 即可），
并把 `.env` 里 `CORS_ALLOWED_ORIGINS` 改成真实访问地址。

## 5. 启动后验证清单

照着这张单子逐条点一遍，全过说明系统健康：

```text
[ ] 浏览器 http://localhost:8080/api/health/ready
    返回 status: READY（mysql: UP / redis: UP 或 DEGRADED / deepseek: UP 或 NOT_CONFIGURED）

[ ] 注册一个 owner 账号能登录，进入后台看板

[ ] 完成开店向导后，档期日历页能看到生成的时段格子

[] 顾客端（未登录访问 5173）发一句"明天有什么时段？"
    填了 DeepSeek Key：AI 正常回答并展示调用轨迹时间线
    没填 Key：走 FAQ 降级回答或提示转人工 —— 这也是正常表现

[] 让 AI 帮你订一个时段，成功后出现预约卡片；
    老板端"今日预约"里同步出现这条预约

[] 在顾客端"我的预约"里能改期、能取消；取消后时段库存回来
```

## 6. 降级运行说明（什么时候"少什么"也能跑）

```text
缺 Redis          启动日志提示 Redis 不可用，系统继续运行：
                  短期记忆/幂等/限流退化为进程内实现（重启后清零），
                  订单、档期、知识库等业务数据完全不受影响。
                  想补上：运行 scripts\setup-redis.ps1 -Start 一键安装
                  项目内便携版（约 12MB，删除项目文件夹即清除）。

缺 DeepSeek Key   后端正常启动；顾客对话走 FAQ 关键词匹配，
                  匹配不上的问题自动创建转人工工单。老板在
                  知识库里补充答案后，同类问题下次就能答上。

MySQL 连不上      后端启动失败或就绪检查返回 NOT_READY —— 这是
                  唯一不可缺的依赖，请先启动 MySQL。
```

## 8. 常见问题

**Q1：启动脚本报"8080 端口被占用"**
上次的后端没停干净。双击桌面**「店小约 - 停止」**即可清理；若仍有残留，
执行 `Get-NetTCPConnection -LocalPort 8080` 找到 PID，`Stop-Process -Id <PID> -Force` 结束它（5173 同理）。

**Q2：后端启动失败，日志里 Access denied for user**
`.env` 里 DB_PASSWORD 和真实 MySQL 密码不一致，改完保存重跑。

**Q3：就绪检查返回 NOT_READY / 503，mysql: DOWN**
两种可能：① 没执行第 ① 步的建库脚本；② MySQL 服务没启动。先 `Test-NetConnection localhost -Port 3306` 确认服务在，再确认脚本执行过。

**Q4：AI 对话一直转人工 / 提示未配置**
AI 密钥未配置或无效。推荐：老板登录网页「店铺设置 → AI 客服设置」填写 Key（保存即生效，无需重启）；
也可在 `backend-java\.env` 里填 DEEPSEEK_API_KEY 后重启后端。没 Key 也能继续用（FAQ 模式），不影响预约功能。

**Q5：JWT_SECRET 相关启动报错**
密钥不足 32 字节会拒绝启动（安全设计）。随便编一段 32+ 字符的乱串填进去。

**Q6：中文乱码**
确认 MySQL 建库时用了 utf8mb4（第 ① 步脚本已内置，手敲建库才会漏）；浏览器乱码一般是终端编码问题，不影响数据库数据。

**Q7：怎么彻底重置演示数据**
停掉服务后执行：

```powershell
mysql -u root -p -e "DROP DATABASE shop_booking;"
mysql -u root -p < database\sql\01_schema.sql
```

所有账号、店铺、预约清零，重新从第 ⑤ 步开始。

**Q8：怎么只重启后端不改前端**
按 Ctrl+C 停脚本（会同时停前端），然后参照第 4 节手动启动后端，前端窗口不动即可。
